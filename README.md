# credit-card-fraud-detection
مشروع ذكاء اصطناعي يهدف إلى اكتشاف العمليات الاحتيالية في البطاقات الائتمانية بدقة عالية. قمت ببناء ومقارنة نماذج تعلم آلة مختلفة (Single Perceptron مقابل Deep Neural Network)، مع معالجة مشكلة عدم توازن البيانات (Class Imbalance) باستخدام تقنية SMOTE لتحسين دقة النموذج وتقليل التنبؤات الخاطئة.
